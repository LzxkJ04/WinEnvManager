# WinEnv管家 v1.1.0

> 首个公开版本。Windows 环境变量与开发环境一体化管理工具。

## 新增功能
- **项目独立环境**：绑定项目文件夹，启动终端时注入变量，仅对该终端进程生效，不写注册表；支持启动前脚本（CMD / PowerShell / Windows Terminal），可选读取项目内 `.env`
- **配置集互斥组**：同组配置集互斥激活，切换 JDK / Python 等多版本环境时不会出现两套变量同时生效
- **事务级快照恢复**：按快照生成变更集后一次应用；任一项失败自动反向回滚，回滚仍失败时按临时快照补写
- **快照完整性校验**：新快照写入前对整份文档计算 SHA256，恢复时校验，被篡改可被发现
- **`.env` / properties 可视化导入**：字段映射向导，导入前预检新增、覆盖、阻断项与循环引用
- **软件识别规则可视化编辑器**：自定义开发工具识别规则库
- **全局跨页搜索**：检索变量、配置集、快照、审计日志与工具箱
- **首次启动向导**：欢迎引导、主题选择、数据目录、权限说明、快照建议、扫描项

## 优化
- Inno Setup 安装包支持自定义程序目录与用户数据目录；提供带前置检测（系统版本 / 权限 / WebView2 / 磁盘空间 / 占用进程）的图形化安装向导
- 完整浅色 / 深色 / 跟随系统三态主题，组件与样式同步切换
- 统一表格组件与弹窗宿主，高危操作二次确认
- 敏感变量脱敏导出覆盖批量导出、配置集与工具箱
- 全套产品图标重绘（窗口 / 任务栏 / 托盘深浅两版 / 侧栏 logo / 安装包 / 安装向导），托盘图标按系统 DPI 选择 16 / 24 / 32 / 48 尺寸

## Bug 修复
- 保存弹窗点击后只剩灰色遮罩、对话框不显示
- 关闭弹窗动画时缩放动画停在 `opacity: 0`，遮罩可见但内容透明
- 通用确认框记住的拖拽位置可能落在屏幕外
- 快照列表在同时存在 `.json` 与 `.json.gz` 时未优先读取压缩版本
- 互斥组拒绝第二个成员加入
- 项目终端会把 `ELECTRON_RUN_AS_NODE` 传给子进程
- 带依赖的软件部署时，依赖失败后续排队任务一直挂起
- 配置集临时终端以用户 PATH 覆盖系统 PATH

## 重要提示

1. 修改**系统环境变量需要管理员权限**，高危操作建议先创建系统快照备份。
2. 项目环境的终端注入变量仅存活于当前终端进程，关闭终端即销毁，不会写入系统全局环境。
3. 用户数据（快照、配置、缓存）默认存储于 `%LOCALAPPDATA%\WinEnvManager`，安装包本体存放 ProgramFiles。便携版数据跟随程序目录。
4. 安装包**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」。这是预期行为，请以 SHA256 校验结果为准。
5. 卸载默认保留用户数据目录（含快照与备份），需要清理请手动删除或卸载时勾选删除用户数据。

## 已知限制

- 仅支持 Windows x64
- `wenv.exe` 命令行工具仅提供编译产物，源码暂未纳入仓库；内置 `--cli` 模式可用
- 界面英文切换只影响组件语言（分页、日期、空状态），页面文案仍为中文
