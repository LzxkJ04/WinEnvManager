# WinEnv管家 v1.2.1

补丁版本，修复 v1.2.0 中注册表恢复、变更监控来源判定与定时任务参数未生效等问题。建议所有 v1.2.0 用户升级。

## 🐛 Bug 修复

### 注册表

- **恢复无法重建被删除的子项**：递归读取时，子项路径带有 PowerShell 提供程序前缀（`Microsoft.PowerShell.Core\Registry::HKEY_...`），恢复时被误判为非法根项并触发整体回滚。现在统一剥离前缀，恢复可完整还原「新增 / 修改 / 删除」三类差异
- **变更监控来源误判**：原先只按「路径 + 10 秒时间窗」判断写入来源，恢复或写入后 10 秒内，外部程序对同一分支的任何改动都会被标成「WinEnv管家」。现改为「路径 + 键名 + 写入值」三项精确匹配，并逐条判定

### 健康诊断

- **进入页面回填上一次结果**：原先只显示上次扫描时间，得分显示 `—`、问题列表为空，必须重新扫描。现在一并返回并回填上次结果

### 定时任务

- **任务参数真正生效**：审计日志导出目录、注册表备份分支、健康报告目录、快照「标记保护」四项参数此前均未传给执行体，界面里填了也不起作用。现已全部接通
- **审计导出路径可见**：原先固定写到数据目录下的 `exports/`，用户配置的目录被忽略

### 其他

- 测试脚本自清理遗漏：定时任务测试的清理前缀拼写错误，每轮会残留一个备份文件

## ⚠️ 升级说明

- 覆盖安装即可，用户配置、快照、注册表备份、定时任务定义均保留
- 已有定时任务无需重建，参数会按新逻辑生效
- 若此前用「标记保护」创建过定时快照任务，升级后新产生的快照才会带保护标记

## ⚠️ 重要提示

1. 修改**系统环境变量与注册表需要管理员权限**，高危操作建议先创建快照或注册表备份。
2. 定时任务仅允许只读 / 备份类操作，修改类操作在类型层面即被拒绝。
3. 用户数据默认存储于 `%LOCALAPPDATA%\WinEnvManager`；便携版跟随程序目录下的 `UserData\`。
