# WinEnv管家 v1.2.0

> 新增注册表管理、环境健康诊断、定时任务、全配置打包四大模块。

## 新增功能

### 注册表管理
- **可视化浏览**：HKCR / HKCU / HKLM / HKU 四根项，树节点异步懒加载，不在打开页面时全量扫描
- **环境变量分支高亮**：`HKCU\Environment` 与 `HKLM\...\Session Manager\Environment` 自动用主色标记，支持一键定位
- **完整键值类型支持**：REG_SZ / REG_EXPAND_SZ / REG_MULTI_SZ / REG_DWORD / REG_QWORD / REG_BINARY，按类型提供专用编辑界面（数字支持十六进制切换、二进制带偶长校验）
- **类型不降级**：写 `REG_EXPAND_SZ` 走 `ExpandString`，不会被系统降级成 `REG_SZ`
- **权限保护**：HKLM 等分支在未提权时自动进入只读模式，编辑按钮置灰并说明原因

### 备份与恢复
- **双格式备份**：原生 `.reg`（可直接双击导入）与带 SHA256 完整性校验的自定义 JSON
- **事务化恢复**：恢复前校验哈希 → 预读差异生成变更清单 → 写入失败自动反向回滚 → 恢复前自动建保底备份
- **备份保护与清理**：支持保护标记，批量清理时跳过受保护备份

### 对比与依赖分析
- **对比**：两备份之间、备份与当前状态之间，差异按新增（绿）/ 修改（黄）/ 删除（红）标记，可导出 HTML / CSV 报告
- **选择性应用**：可勾选部分差异条目应用，不必全量执行；支持一键生成反向回滚清单
- **依赖分析**：提取 `%VAR%` 引用，识别无效引用与循环引用，生成依赖关系图，支持反向查找引用某变量的全部注册表项

### 变更监控
- 轮询监听指定分支，记录新增 / 修改 / 删除事件
- 区分「本软件」与「外部」来源
- 不在软件启动时自动恢复监听，避免意外资源占用

### 批量查找替换
- 仅处理字符串类型（REG_SZ / REG_EXPAND_SZ），二进制与数字类型跳过
- **强制预览**：扫描结果表格标出全部待改条目，可逐条取消勾选
- 执行前自动创建分支临时备份，单条失败跳过不影响其余

### 注册表收藏夹
- 内置两条环境变量预设（不可删除，可隐藏）
- 支持自定义分组、重命名、移动、隐藏
- 支持 JSON 导入导出，便携模式下随 UserData 目录迁移

### 环境健康诊断
- **9 类检测项**：PATH 重复 / 路径不存在 / 格式异常、无效引用、循环引用、注册表键值类型异常、互斥组冲突、项目文件夹丢失、工具路径失效
- 0~100 健康评分与严重 / 警告 / 提示分级统计
- 诊断报告导出 HTML / Markdown
- **预览式修复**：先展示变更清单，用户确认后执行，修复前自动备份

### 定时任务
- 依托 Windows 任务计划程序，软件关闭仍可触发
- 支持四类**只读/备份**任务：系统环境快照、注册表分支备份、审计日志导出、健康诊断
- 支持每日 / 每周 / 每月，可选「仅在空闲时运行」与「错过补执行」
- 修改类操作（变量或注册表写入）**禁止**定时执行，后端强校验拒绝
- 程序目录变更后自动标记为「失效任务」并提示重建

### 全配置打包
- 一键打包软件自身全部自定义配置为单个 `.wemcfg` 文件
- 支持密码加密（AES-256-GCM），manifest 记录版本与模块清单并附 SHA256
- 导入支持覆盖 / 合并 / 仅选中模块，导入前自动备份当前配置防止丢失

## 优化

- 全局搜索新增「注册表收藏」「定时任务」两个数据源
- 审计日志新增注册表、配置包、健康诊断、定时任务类筛选（15 个动作类型）
- 环境变量总览页新增「诊断中心」「查看底层注册表」快捷入口
- 设置页新增「注册表设置」「定时任务设置」「配置备份与恢复」三个分组
- REG 导入改为四步向导：选文件 → 预览标色 → 选模式 → 高危确认

## 安全约束

- 定时任务只允许只读 / 备份类操作，修改环境变量或注册表的任务类型在后端被强校验拒绝
- 所有注册表写操作走 PowerShell `-EncodedCommand`，不做命令行字符串拼接，规避引号与中文编码问题
- 高危操作统一使用全局高危确认弹窗，必须勾选风险确认后方可执行
- 不做自动注册表垃圾清理、一键优化、碎片整理等高风险操作

## 重要提示

1. **注册表修改比环境变量更危险**，可能造成程序异常甚至系统无法启动。修改前请务必先对该分支创建注册表备份。
2. 修改**系统级环境变量与 HKLM 分支需要管理员权限**，未提权时只读浏览。
3. 定时任务只做备份、扫描、导出类只读操作，不会自动修改任何环境变量或注册表。
4. 用户数据（快照、注册表备份、配置、缓存）默认存储于 `%LOCALAPPDATA%\WinEnvManager`，安装包本体存放 ProgramFiles。便携版数据跟随程序目录。
5. 安装包**未做代码签名**，Windows SmartScreen 可能提示「未知发布者」。这是预期行为，请以 SHA256 校验结果为准。
6. 卸载默认保留用户数据目录（含快照与备份），需要清理请手动删除或卸载时勾选删除用户数据。

## 已知限制

- 仅支持 Windows x64，不支持远程 / 网络注册表
- 注册表变更监控为轮询实现（默认 3 秒），两次轮询之间的瞬时变化可能漏检，不适合作为审计取证
- 依赖分析仅识别标准 `%VAR%` 格式，不解析 PowerShell 或批处理脚本内的自定义变量语法
- 对比与备份只比较键值，空注册表项（无键值的项）不会体现在差异中
- `wenv.exe` 命令行工具仅提供编译产物，源码未纳入仓库；内置 `--cli` 模式可用
